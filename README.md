# 공인중개사 2차 시험 대비 문제 풀이 웹앱

React + TypeScript + Vite 기반의 공인중개사 2차 시험 대비 MVP 웹앱입니다.

## 목표

실제 공인중개사 2차 시험 환경처럼 문제를 풀 수 있는 프로그램을 만듭니다.

핵심 기능:

- 시험 모드 선택
- 과목별 시험 응시
- 실제 시험지형 문제 풀이 UI
- 왼쪽 5지선다 답안 체크테이블
- 타이머 및 일시정지
- 제출 및 자동 채점
- 결과/해설 화면
- 추후 오답 데이터 누적, 약점 피드백, 암기노트 확장

## 시험 구조

### 2차 1교시 모드

- 중개사법 40문항
- 공법 40문항
- 총 80문항
- 제한시간 100분

### 과목별 단독 모드

- 중개사법 단독: 40문항
- 공법 단독: 40문항, 화면 표시 문제번호는 41번~80번 지원
- 공시법/세법 단독: 40문항, 제한시간 50분

## 문제 구성 비율

각 과목 40문항 기준:

| 구분 | 비율 | 문항 수 |
|---|---:|---:|
| 30회~36회 최근 빈출 | 40% | 16문항 |
| 22회~29회 과거 기출/변형 | 20% | 8문항 |
| 최신 부동산 이슈 예상 | 10% | 4문항 |
| 함정 문제 | 20% | 8문항 |
| 쉬운 문제 | 10% | 4문항 |

## MVP 완료 기준

- 샘플 문제 데이터가 있다.
- 시험 설정 화면에서 모드를 선택하고 시험을 시작할 수 있다.
- 시험 응시 화면에서 문제/선택지/왼쪽 5지선다 체크테이블이 동작한다.
- 답 선택 시 체크테이블과 문제 선택 상태가 연동된다.
- 타이머와 일시정지/재개가 동작한다.
- 제출하면 채점 결과와 해설 화면이 나온다.
- 과목별 단독 모드와 2차 1교시 모드가 구분된다.

자세한 구현 지시는 `AGENTS.md`와 `docs/mvp-spec.md`를 참고하세요.
